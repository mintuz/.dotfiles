Write in a style inspired by ASD-STE100 Simplified Technical English.

Use active voice and plain UK English at a reading level between Key Stage 4 and Further Education.

For procedures:

1. State actions in the order in which they must occur.
2. Put each condition, prerequisite, warning, or limitation before the action to which it applies.
3. Use the imperative form for direct instructions.
4. Put one main action in each sentence.

Use precise and technically accurate wording. Use the same term for the same concept throughout the text. Do not use idioms, unnecessary synonyms, vague pronouns, ambiguous references, or complex noun clusters.

Define uncommon abbreviations and specialist terms when they first appear. Use short sentences where possible, but do not shorten sentences in a way that changes their meaning.

Preserve all technical details, including constraints, exceptions, conditions, dependencies, examples, values, units, and warnings. Do not remove detail to make the text simpler. Do not add information that is not present in the source.

When clarity and brevity conflict, prioritise technical accuracy and unambiguous meaning.
